# Bhagavad Gita - Open Knowledge Format

## Overview

Complete knowledge base of 700 verses from the Bhagavad Gita, organized by chapter and verse with rich metadata, semantic tags, and knowledge graph connections.

The Bhagavad Gita is a 700-verse Hindu scripture that is part of the epic Mahabharata. It is a conversation between Prince Arjuna and Lord Krishna on the battlefield of Kurukshetra, covering profound spiritual and philosophical teachings.

## Format

This bundle follows the [Open Knowledge Format (OKF) v0.1 specification](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md).

Each verse is a markdown file with:
- **YAML Frontmatter**: type, title, description, tags, related, metadata
- **Markdown Body**: Sanskrit, Translation, Meaning, Modern Applications
